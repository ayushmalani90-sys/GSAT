# GSAT Systematic Dashboard UI

Preserve the established dark Bloomberg-style terminal appearance.

## Section order
1. Header / live status
2. Live Market — Gold, Silver, Gold/Silver Ratio
3. Visual Reference — Gold and Silver TradingView charts
4. Technical Analysis — Gold and Silver side-by-side
   - Trend / EMA
   - Overall Technical Interpretation
   - Support / Resistance
   - Momentum
   - Volatility / Fibonacci
   - Volume Profile / Pattern Detection
5. Macro Intelligence — bottom of dashboard
6. Footer

## Macro cards
Each macro card contains only the event name, IST release time, Previous, Forecast, Actual.

Do not redesign or remove existing market/technical cards as part of macro changes.
