# GSAT Systematic Dashboard UI

Preserve the established dark Bloomberg-style terminal appearance.

## Section order
1. Header / live status
2. Live Market — Gold, Silver, Gold/Silver Ratio
3. Visual Reference — Gold and Silver TradingView charts
4. Technical Analysis — Gold and Silver side-by-side
5. Macro Intelligence — bottom of dashboard
6. Footer

## Technical card order
- Trend / EMA 20, 50, 200
- Overall Technical Interpretation
- Support / Resistance
- Momentum: RSI 14, MACD 12/26/9
- Volatility: ATR 14
- Fibonacci Retracement
- Volume Profile
- Pattern Detection

## Macro cards
Each macro card contains only:
- event name
- IST release time
- Previous
- Forecast
- Actual

Do not add Gold/Silver rows, explanations, extra badges, or redesign the existing market/technical cards as part of macro work.
